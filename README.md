# TopPin 📌

[中文](README.md) | [English](README_EN.md)

让参考资料、终端或视频留在其他窗口上方。TopPin 是免费开源的 macOS 窗口置顶与画中画工具，运行在菜单栏中。

## 安装

需要 **macOS 14.0 或更高版本**，支持 Apple Silicon 和 Intel Mac。

### 直接下载

1. 前往 [GitHub Releases](https://github.com/Canlendula/PinTop/releases) 下载 macOS 安装包。
2. 解压后，将 **TopPin.app** 拖入“应用程序”文件夹。
3. 打开 TopPin，在菜单栏找到图钉图标。

### Homebrew

计划支持 Homebrew 安装，安装命令将在发布后补充。

## 开始使用

1. 首次启动时，按提示授予屏幕录制和辅助功能权限。
2. 切换到想置顶的窗口，按 **⌃⌥P**（Control + Option + P）。也可以从菜单栏的“选择窗口置顶”中选择窗口。
3. 在菜单栏中调整置顶模式、画中画比例、不透明度和鼠标穿透。
4. 再次按 **⌃⌥P** 取消当前窗口置顶，或按 **⌃⌥⇧P** 取消全部置顶。

TopPin 通过实时镜像显示置顶窗口。单击镜像会切回原窗口，方便继续操作。

## 功能

- **智能置顶**：默认只在原窗口被遮挡时显示置顶层；原窗口未被遮挡时，直接使用原窗口。
- **始终悬浮**：可为每个置顶窗口单独开启，适合长时间查看参考资料或画中画。
- **多个窗口**：支持同时置顶多个窗口，菜单栏显示当前置顶数量。
- **画中画**：支持 100%、75%、50%、33% 和 25% 缩放，可拖拽到屏幕其他位置。
- **不透明度**：支持 100%、90%、80%、70%、50% 和 30% 调节。
- **鼠标穿透**：仅显示置顶内容，让点击落在下方窗口。
- **滚动原窗口**：在置顶层上滚动，无需先切换到原窗口。
- **自动化配合**：支持模拟点击穿透，并提供置顶层的截图和录屏可见性选项，方便配合 Computer Use 使用。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| **⌃⌥P** · Control + Option + P | 置顶 / 取消置顶当前窗口 |
| **⌃⌥⇧P** · Control + Option + Shift + P | 取消全部置顶 |
| **⌃⌥T** · Control + Option + T | 切换最上层置顶窗口的鼠标穿透 |
| **⌃⌥O** · Control + Option + O | 循环切换不透明度：100% → 80% → 60% → 40% |

## 鼠标操作

| 操作 | 效果 |
| --- | --- |
| 单击 / 双击置顶层 | 切换到原窗口 |
| 拖拽置顶层 | 移动悬浮位置 |
| 在置顶层上滚动 | 滚动原窗口内容 |
| 右键置顶层 | 打开缩放、不透明度、穿透和取消置顶等选项 |

开启鼠标穿透后，可通过菜单栏或快捷键调整置顶窗口。

## 设置

点击菜单栏图钉图标，打开“设置”，可以调整：

- 新置顶窗口的默认悬浮模式和默认不透明度；默认值的修改不会覆盖已有窗口的选择。
- 自动化点击穿透、滚动转发和截图 / 录屏可见性。
- 置顶边框、刷新帧率（15 / 30 / 60 fps）和登录时启动。

## 权限

TopPin 需要以下两项权限：

| 权限 | 用途 |
| --- | --- |
| 屏幕录制（录屏与系统录音） | 实时显示被置顶窗口的内容 |
| 辅助功能 | 点击置顶层时切换到原窗口 |

可在 **系统设置 › 隐私与安全** 中管理这些权限。修改权限后，按系统提示重新打开 TopPin。
